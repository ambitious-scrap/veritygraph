# proof-carrying-research

An evidence-first multi-agent research system that verifies every important claim before compiling the final report.

## Core MVP
- Research query input
- Claim extraction
- Evidence retrieval
- Support/contradiction verdicts
- Confidence scoring
- Verified report

## Planned Stack
- Next.js frontend
- FastAPI backend
- LangGraph orchestration
- PostgreSQL
- Tavily/Hound retrieval
